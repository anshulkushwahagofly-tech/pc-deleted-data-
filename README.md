# PC Deleted Data Backup

Yeh repository un sabhi projects, codefiles aur assets ka complete backup hai jo local PC se remove kiye gaye hain.

## 📁 Is Backup Repository ke Folders:

1. **`JarvisAI/`**
   - AI assistant project code aur scripts.
2. **`instagram_3d_clone/`**
   - Instagram 3D web clone files aur 3D viewer implementation.
3. **`meesho_tailwind/`**
   - Meesho frontend clone using Tailwind CSS.
4. **`igloo-clone/` & `igloo_clone/`**
   - Full 3D Igloo website clone (3D models, textures, shaders, audio, sound effects, scripts).
5. **`skyclinics-clone/`**
   - Skyclinics website clone (including 3D models `.glb`, assets, video files, aur components).
6. **`card_clone/`**
   - Card payment & interactive card UI clone with form validation and responsive logic.
7. **`meesho_project/` & `meesho_clone/`**
   - Meesho full clone files, scrapers, grid components, and Wayback snapshots.
8. **`anshulkushwaha-jhansi/`**
   - Personal profile / portfolio site and assets.
9. **`steam_clone/`**
   - Steam gaming platform interface clone.
10. **`temp_check/`**
    - Additional responsive & 3D tests and assets.
11. **`main_portfolio_website/`**
    - Main portfolio website code (`index.html`, `style.css`, `script.js`, `assets/`, helper scripts).
